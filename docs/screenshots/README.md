# Screenshots

Current-state captures used in pull request descriptions, taken against a production
build (`pnpm build` + `pnpm preview`) with `chrome-devtools-axi`.

Viewports: desktop `1280x900`, mobile `390x844` (iPhone 15 Pro Max logical size).
Captured at a device pixel ratio of 1 to keep the committed files small - the layout
is the point, not the pixel density.

Regenerate by driving the CLI against a local preview; see the test plan in the PR
description for the exact states shown.
